# Portfolio

> 🚧 **Note**: This project is currently under construction and active development.

A portfolio website built with Next.js, React, Tailwind CSS, and Framer Motion. Features scroll-driven canvas frame animation and smooth scrolling.

---

## ✨ Features

- **Canvas Image Sequence**: Scroll-driven frame animation rendered on HTML5 Canvas.
- **Smooth Scrolling**: Momentum scrolling powered by Lenis.
- **Custom Cursor**: Interactive cursor with hover states and particle trail.
- **Text Transitions**: Scroll-synchronized typography animations with Framer Motion.
- **Responsive Layout**: Dark theme design across mobile, tablet, and desktop.
